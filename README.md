# Spring Security with JWT Authentication

A Spring Boot project demonstrating user registration, authentication, and role-based authorization using Spring Security and JSON Web Tokens (JWT).

## Features

- User registration and login
- Spring Security configuration
- JWT-based authentication
- Role-based authorization for users and administrators
- Password encryption using BCrypt
- PostgreSQL database integration
- REST API development

## Technologies Used

- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- PostgreSQL
- Maven
- Eclipse IDE

## Project Structure

```text
src/main/java
└── com.example.demo_spring_security
    ├── configuration
    ├── controller
    ├── dto
    ├── entity
    ├── exception
    ├── repository
    └── service
```

## Getting Started

1. Clone this repository.
2. Configure your PostgreSQL database.
3. Update your database settings and JWT secret using your local configuration.
4. Run the application from your IDE or using Maven.

## Learning Purpose

This project is built for learning and practicing Spring Security, JWT authentication, and role-based access control.
